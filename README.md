### デモ用のメモ

- Assets/Scenes/Demo/VRWindowSystem.unity を再生するとデモができる
  - C キーを押す：ビルを操作するデモに移動
  - W キーを押す：ウィンドウシステムのデモに戻る
  - ※ 環境をリセットしたい場合、一度別のデモに切り替えて戻すとよい
- このシーンでは Quest Pro の Gaze を使って手を切り替えている
  - Tab キーを押すことで、デモ実施者が手動で切り替えることも可能
